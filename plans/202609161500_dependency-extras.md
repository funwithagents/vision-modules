# Dependency extras

**Status:** Done

Implements the settled behavior in `specs/project.md` ("Runtime dependencies are split by feature"). This plan delivers **only** the dependency layout in `pyproject.toml` (core runtime deps plus the feature-named `hand` extra), the regenerated lock file, and a README install line. It writes **no library code** — the concept specs (`stream`, `pipeline`, `hand`, `gesture_classifier`) get their own plans.

## Context you need before starting

- Read `AGENTS.md` (status rules, commands) and `specs/project.md` ("Decided" section) first.
- The project uses `uv`. Never run `pip` directly; every command below is a `uv` command run from the repo root.
- Today `pyproject.toml` has `dependencies = []` and one dependency group, `dev`, holding `pyright`, `pytest`, `ruff`. There are no optional extras yet.
- **Already verified** (on 2026-09-16, `uv 0.11.29`): all six packages resolve for Python 3.12 on macOS arm64 — `numpy 2.5.3`, `opencv-python 5.0.0.93`, `mediapipe 1.0.1`, `torch 2.11.0`, `transformers 5.17.0`, `pillow 12.3.0`. You do not need to re-check wheel availability; you do need `uv` to succeed on your machine.
- Expect the first `uv sync` to download a lot (torch alone is hundreds of MB). That is normal.

- `uv.lock` — regenerated by `uv` (never hand-edit it).
- `README.md` — one line telling users how to install with the extra.
- `specs/project.md` and `specs/_index.md` — status flip `Updated` → `Implemented` at the end.

## Target end state of `pyproject.toml`

Only the sections shown change; every other section stays exactly as it is. Version pins are whatever `uv` writes when you run the commands in the Steps — do not invent pins.

```toml
[project]
# ... name, version, description, readme, authors, requires-python unchanged ...
dependencies = [
    "numpy>=2.5",
    "opencv-python>=5.0",
]

[project.optional-dependencies]
# One extra per feature family (specs/project.md). `hand` covers the shared hand
# stage (mediapipe) and the gesture classifier (torch, transformers, pillow).
hand = [
    "mediapipe>=1.0",
    "torch>=2.11",
    "transformers>=5.17",
    "pillow>=12.3",
]

[dependency-groups]
dev = [
    "vision-modules[hand]",   # dev installs every extra so the full test suite can import everything
    "pyright>=1.1.414",
    "pytest>=9.1.1",
    "ruff>=0.16.8",
]
```

## Steps

Run each step's command, check its expected result, then move on. If a command fails, stop and fix that step before continuing — do not skip ahead.

1. **Mark this plan `In progress`.** Change `**Status:** Todo` to `**Status:** In progress` at the top of this file, and change the `Todo` cell of this plan's row in `plans/_index.md` to `In progress`.

2. **Add the core runtime dependencies.**
   ```
   uv add numpy opencv-python
   ```
   Expected: `pyproject.toml` now has `numpy` and `opencv-python` under `dependencies`, `uv.lock` changed, and the command ends without error. Open `pyproject.toml` and confirm the two lines are there.

3. **Add the `hand` extra.**
   ```
   uv add --optional hand mediapipe torch transformers pillow
   ```
   Expected: `pyproject.toml` now has a `[project.optional-dependencies]` table with `hand = [...]` listing the four packages. Confirm by reading the file.

4. **Make the `dev` group include the extra.** Edit `pyproject.toml` by hand: inside `[dependency-groups]`, add the line `"vision-modules[hand]",` as the first entry of the `dev` list (see "Target end state" above). Then run:
   ```
   uv sync --dev
   ```
   Expected: completes without error and installs mediapipe / torch / transformers / pillow into `.venv`.

   **If `uv sync --dev` rejects the self-reference** (an error mentioning `vision-modules[hand]` in the `dev` group), fall back to: remove that line again, and instead run `uv sync --dev --all-extras`. In that case also change the `uv sync --dev` line to `uv sync --dev --all-extras` in **both** `AGENTS.md` ("Commands") and `README.md` ("Development"), so the documented command installs everything. Note which path you took in the "Verification" section of this file.

5. **Prove every runtime import resolves inside the venv.**
   ```
   uv run python -c "import numpy, cv2, mediapipe, torch, transformers, PIL; print('imports ok')"
   ```
   Expected output: exactly `imports ok`. (`cv2` is the import name of `opencv-python`; `PIL` is the import name of `pillow`.) If any import fails, the extra is wrong — go back to step 3.

6. **Add the install line to `README.md`.** In the "Development" section, right after the sentence that starts "This project is built spec-first", add this paragraph:

   (If you took the fallback in step 4, end that paragraph with `uv sync --dev --all-extras` instead.)
