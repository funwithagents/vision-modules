# Continuous integration

**Status:** In progress

Implements [specs/ci.md](../specs/ci.md) and the "Platforms" and CPU-torch decisions in [specs/project.md](../specs/project.md). It delivers one GitHub Actions workflow with five jobs: `check`, `fast-tier` × 3 platforms, and `e2e` on Linux. It also moves Linux torch onto the PyTorch CPU index. It leaves out the live tier on macOS and Windows and any Python axis (ci.md open questions 1 and 2), and the branch protection setting, which lives on GitHub.

## Scope

- `pyproject.toml`: a `pytorch-cpu` `[[tool.uv.index]]` (explicit) and a `[tool.uv.sources]` entry pinning `torch` to it on Linux.
- `uv.lock`: relocked. Linux torch becomes `+cpu`, and the `nvidia-*` / `triton` packages leave the lock.
- `.github/workflows/ci.yml`: the workflow.
- `specs/ci.md` (new), `specs/project.md`, `specs/testing.md`, `specs/_index.md`: the design. `project.md` goes `Implemented` → `Updated` → `Implemented`, and `ci.md` goes `Stable` → `Implemented`.
- `AGENTS.md`: a `.github/workflows/` row in the project map, and a CI note under Verification.

## Steps

1. **CPU torch on Linux.** Add the index and the source to `pyproject.toml`, then `uv lock`. Check that the lock has no `nvidia-*` package left and that `torch` resolves to `2.14.x+cpu` for `sys_platform == 'linux'` and to PyPI's wheel elsewhere.
2. **The workflow.** Triggers: `pull_request`, `push` to `main`, `workflow_dispatch`. Concurrency is grouped by ref with `cancel-in-progress`. Every job uses `actions/checkout`, `astral-sh/setup-uv` with its cache keyed on `uv.lock`, then `uv sync --locked`.
   - `check` on `ubuntu-24.04`: `ruff check .`, `ruff format --check .`, `pyright`.
   - `fast-tier`: a matrix over `ubuntu-24.04`, `macos-15`, `windows-2025` with `fail-fast: false`, running `uv run pytest`.
   - `e2e` on `ubuntu-24.04`: `actions/cache` over `~/.cache/vision-modules` and `~/.cache/huggingface`, keyed on `hashFiles` of `hand.py`, `face.py`, `gesture_classifier.py` with no restore keys. Then `uv run pytest tests-e2e -rs`.
   - Each job gets a `timeout-minutes`.
3. **Push the branch and open the PR.** Read every job's log: all five are green, and the `e2e` log shows exactly the two expected skips in ci.md.
4. **Statuses.** Mark this plan `Done`, `ci.md` `Implemented` and `project.md` back to `Implemented`, in the files and the indexes.

## Verification

- Locally: `uv run ruff check .`, `uv run ruff format --check .`, `uv run pyright`, `uv run pytest`, and `uv run pytest tests-e2e -rs` after the relock. The live tier reports exactly the two expected skips.
- On GitHub: the PR's run has all five jobs green, and the `e2e` log's skip summary matches ci.md's table.
