# Snapshot: save a node's current frame to a file

**Status:** Done

Implements the settled behavior in `specs/snapshot.md` ("API", "Invariants"). Delivers `save_frame` and `save_crops` as pure functions over already-published values (`Frame`, `HandResult`), exported from the package root, with pixel-exact round-trip tests. Deliberately leaves out sidecar metadata, a demo button and annotated snapshots (the spec's three open questions).

## Scope

- `src/vision_modules/snapshot.py` — new module: `save_frame`, `save_crops`, one private `_write` helper (suffix check, parent mkdir, `imwrite`, `False` → `OSError`).
- `src/vision_modules/__init__.py` — re-export both functions, extend `__all__` and the module docstring.
- `tests/test_snapshot.py` — functional tests: round-trip pixels, directory creation, index-aligned crop naming, `None`/unsupported-suffix errors, and an end-to-end drive through `StreamProvider` → `HandStage` with a scripted detector.
- `AGENTS.md` — project-map row for `snapshot.py`.
- `README.md` — row in "What's in the box", `### Snapshot` section under "API overview".
- `specs/_index.md`, `plans/_index.md` — rows; statuses flipped when done.

## Steps

1. **`_write(image, path) -> Path`.** `path = Path(path)`; `if not cv2.haveImageWriter(str(path)): raise ValueError(...)`; `path.parent.mkdir(parents=True, exist_ok=True)`; `if not cv2.imwrite(str(path), image): raise OSError(...)`; return `path`.
2. **`save_frame(frame, path)`.** `None` → `ValueError("no frame published yet")`; else `_write(frame.image, path)`.
3. **`save_crops(result, path)`.** `None` → `ValueError`; `path = Path(path)`; for `i, hand in enumerate(result.hands)`: `None` crop → `None`, else `_write(hand.crop, path.with_name(f"{path.stem}_{i}{path.suffix}"))`. Return the tuple.
4. **Exports.** Add to `__init__.py` imports and `__all__` (sorted), mention in the docstring.
5. **Tests** (`tests/test_snapshot.py`), driving the public API:
   - `save_frame` on a known gradient BGR image to `.png` under `tmp_path`: `cv2.imread` returns an identical array (shape and `np.array_equal`), the source image is unchanged, and the returned `Path` is the file.
   - `save_frame` into a nested path whose directories don't exist creates them.
   - `save_frame` with `.jpg` writes a readable file of the right shape (lossy, so no pixel equality).
   - `save_frame(None, …)` raises `ValueError`; an unsupported suffix (`.txt`) raises `ValueError` and leaves nothing on disk.
   - `save_crops` on a `HandResult` with two hands, the second with `crop=None`: returns `(tmp/crop_0.png, None)`, `crop_0.png` round-trips the first crop, no `crop_1.png` exists.
   - `save_crops` on an empty result returns `()` and writes nothing; `save_crops(None, …)` raises `ValueError`.
   - End to end: a `StreamProvider` over a stepped source feeding one known frame, a `HandStage` with a scripted detector and `pad=0`; after both have published, `save_frame(provider.latest(), …)` and `save_crops(hands.latest(), …)`; read both back and assert the crop file equals the frame file sliced by `bbox`.
6. **Docs.** AGENTS.md map row; README table row and API section (spec's `save_frame`/`save_crops` block plus the `frame_id`-matching example for `GestureClassifier`).
7. **Statuses.** Spec `Stable` → `Implemented`, this plan → `Done`, both in file and index, in the same change as the verified code.
