# Stage timings: when each stage started and finished a result

**Status:** Done

Implements the settled behavior in `specs/pipeline.md` ("Stage timings"), with the clock rule in `specs/stream.md` and the per-result wording in `specs/hand.md` and `specs/gesture_classifier.md`. Delivers `StageTiming(name, started_at, computed_at)` and `Result.timings`, stamped by the runtime as a stage publishes and carried from each result to the results built from it, so a host can split a result's age into waiting and computing, per stage. Deliberately leaves out any change to the stages themselves, any configuration, wall-clock stamps, OpenTelemetry, a timing for the frame provider, clamping of the stamps, and any display in the hand demo.

## Scope

- `src/vision_modules/pipeline.py` — `StageTiming`; keyword-only `Result.timings`; `Stage._run` reads the clock around `process()` and publishes a `Result` with the input's timings plus its own.
- `src/vision_modules/__init__.py` — export `StageTiming`.
- `tests/test_pipeline.py` — the runtime's stamping, on generic stages.
- `tests/test_hand.py` — `HandResult` timings, from a `Frame` and from a foreign frame class.
- `tests/test_gesture_classifier.py` — `Gesture` timings over a real `HandStage` → `GestureClassifier` chain with scripted backends.
- `README.md` — `timings` in the key rules and the pipeline API block.
- `specs/pipeline.md`, `specs/stream.md`, `specs/hand.md`, `specs/gesture_classifier.md`, `specs/_index.md` — the design; `pipeline.md` goes `Updated` while the code lags and back to `Implemented` when this plan is `Done`.
- `plans/_index.md` — this plan's row.
- `.gitignore` — `analysis/` (local handoff notes stay out of the repository).

## Steps

1. **Types.** In `pipeline.py`, add the frozen dataclass `StageTiming(name, started_at, computed_at)` and the field `timings: tuple[StageTiming, ...] = field(default=(), kw_only=True)` on `Result`. Keyword-only is what lets `HandResult` and `Gesture` keep their own non-default fields, and keeps every existing `Result(frame_id, ts, present)` call valid.
2. **Stamping.** In `Stage._run`, read `time.monotonic()` just before `process(item)` and just after it returns. When the output is not `None`, publish `_stamped(out, item, own)`: for a `Result`, `dataclasses.replace(out, timings=(*getattr(item, "timings", ()), own))`; any other output unchanged. Nothing is stamped when `process()` raises or returns `None`.
3. **Export.** Add `StageTiming` to `__init__.py` imports and `__all__`.
4. **Runtime tests** (`test_pipeline.py`): one timing whose stamps bracket a clock reading taken inside `process()`; a stage that sleeps shows the delay; the default name is the class name; a downstream result carries the upstream's timing then its own, in order; with the upstream racing ahead, the carried timing is the one of the consumed frame and not of the upstream's newest; an input without `timings` gives one timing; timings set by `process()` are replaced; a non-`Result` output is published as the same object.
5. **Hand tests** (`test_hand.py`): a `HandResult` carries one timing named `HandStage` with `ts <= started_at <= computed_at` and a slow detector's delay inside it; an empty frame carries one too; so does a result built from a foreign frame class on a foreign slot.
6. **Chain tests** (`test_gesture_classifier.py`): over `HandStage` → `GestureClassifier` with scripted backends, a `Gesture` carries two timings, the hand stage's first and equal to the one on the `HandResult` of the same frame, with the hand stage's `computed_at <=` the classifier's `started_at`; with the classifier held inside frame 1 while the hand stage publishes frame 2, the `Gesture` for frame 1 still carries frame 1's hand timing; a classifier at 5 fps shows the wait before its `started_at` for a hand result that landed just after its last look; a `Gesture` built from a hand result without timings carries only its own.
7. **Clock-safe assertions.** The fast tier runs on Windows with a ~15.6 ms clock tick: frames in these tests take `ts` from `time.monotonic()` directly, orderings are asserted with `<=`, and two timings are only asserted different when more than a tick apart.
8. **Docs and statuses.** README; `pipeline.md` back to `Implemented` (file and index); this plan `Done`.
