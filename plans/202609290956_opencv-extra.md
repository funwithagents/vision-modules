# OpenCV extra: a numpy-only core

**Status:** Done

Implements the settled behavior in `specs/project.md` ("Runtime dependencies are split by feature; the core depends on `numpy` alone" and "The core imports no optional package at module level"), plus the matching edits in `specs/stream.md` ("OpenCV is optional", `mirror`), `specs/snapshot.md` ("Writing needs the `opencv` extra; importing does not"), `specs/hand.md` and `specs/gesture_classifier.md` (numpy BGR→RGB). Afterwards, `pip install vision-modules` installs only `numpy` and still runs the stream and pipeline runtime over a caller's own `FrameSource`. `pip install "vision-modules[opencv]"` adds webcams, files, URLs and snapshots. The public API and every root export stay unchanged. Out of scope: moving `OpenCVSource` to its own module, trimming the package root, lowering the `numpy` floor, and splitting the `hand` extra.

## Scope

- `pyproject.toml`: move `opencv-python` from `dependencies` to a new `opencv` extra; the `dev` group installs `vision-modules[hand,opencv]`
- `uv.lock`: re-resolved
- `src/vision_modules/stream.py`: no module-level `cv2`; a private `_import_cv2()` helper; `OpenCVSource` imports `cv2` in `open()`; `mirror` becomes a numpy flip
- `src/vision_modules/snapshot.py`: no module-level `cv2`; `_write` gets it from `_import_cv2()`
- `src/vision_modules/hand.py`: drop `import cv2`; BGR→RGB via numpy
- `src/vision_modules/gesture_classifier.py`: drop `import cv2`; BGR→RGB via numpy
- `tests/test_core_imports.py` (new): the subprocess test that pins the numpy-only core
- `tests/test_stream.py`: mirror output byte-identical to `cv2.flip`
- `specs/project.md`: add `tests/test_core_imports.py` to the frontmatter `tests:`
- `README.md`: Installation section and core-dependency wording

## Steps

1. **Dependencies.** In `pyproject.toml`, set `dependencies = ["numpy>=2.5.3"]` and add `opencv = ["opencv-python>=5.0.0.93"]` under `[project.optional-dependencies]`. Change the `dev` group's `"vision-modules[hand]"` to `"vision-modules[hand,opencv]"` (the demo and the test suite import `cv2` directly). Run `uv lock` and `uv sync --dev`.

2. **Lazy `cv2` helper in `stream.py`.** Remove the module-level `import cv2`. Add:

   ```python
   _OPENCV_HINT = 'install the opencv extra: pip install "vision-modules[opencv]"'


   def _import_cv2(feature: str) -> ModuleType:
       try:
           import cv2
       except ImportError as e:
           raise ImportError(f"{feature} requires OpenCV; {_OPENCV_HINT}") from e
       return cv2
   ```

   Keep the `cv2.VideoCapture | None` annotation on `OpenCVSource._cap` by importing `cv2` under `if TYPE_CHECKING:`. The annotation can stay unquoted because annotations inside a function body are never evaluated at runtime. Pyright still checks it in the dev env.

3. **`OpenCVSource`.** In `open()`, call `cv2 = _import_cv2("OpenCVSource")` before creating the capture. Store the module on the instance (`self._cv2`) so `fps()` can read `CAP_PROP_FPS` without importing again. `fps()` only reads it while `_cap` is open, so it's always set by then. `__init__` stays free of side effects, so `StreamProvider(0)` constructs without OpenCV and `start()` raises the `ImportError` from `open()`. `start()` doesn't need to change: it already calls `open()` before setting any running state, so a failed `start()` leaves the provider stopped and restartable.

4. **`mirror`.** In `StreamProvider._run`, replace `cv2.flip(img, 1)` with `np.ascontiguousarray(img[:, ::-1])`. This returns a new contiguous array, so the ownership rule holds.

5. **`snapshot.py`.** Remove the module-level `import cv2`. At the top of `_write`, add `cv2 = _import_cv2("writing a snapshot")` (imported from `vision_modules.stream`). The `ImportError` then comes before the suffix check and before anything touches the disk.

6. **`hand.py` / `gesture_classifier.py`.** Remove `import cv2`. Replace each `cv2.cvtColor(image_bgr, cv2.COLOR_BGR2RGB)` with `np.ascontiguousarray(image_bgr[..., ::-1])`. `mp.Image` needs a C-contiguous buffer. PIL gets one too, for consistency.

7. **Core-import test** (`tests/test_core_imports.py`). Run one `subprocess.run([sys.executable, "-c", SCRIPT])` whose script does the following:
   - blocks the optional packages before any import: `for m in ("cv2", "mediapipe", "torch", "transformers", "PIL"): sys.modules[m] = None`
   - runs `import vision_modules` and `from vision_modules import *`
   - builds a `StreamProvider(stub, mirror=True)` over a tiny in-script `FrameSource` yielding two known arrays and then `None`. It runs this in a `Pipeline` with a minimal `Stage` subclass whose `process` returns the frame's `image.sum()`. It then checks that the stage published the expected value and that the mirrored image equals `img[:, ::-1]`.
   - checks that `StreamProvider(0).start()` raises `ImportError` whose message contains `vision-modules[opencv]`, and that the provider can still be constructed
   - checks that `save_frame(frame, tmp / "x.png")` raises `ImportError` with the same hint, and that no file or parent directory was created

   The test asserts `returncode == 0` and shows stderr on failure. Add `tests/test_core_imports.py` to `specs/project.md`'s frontmatter `tests:` in the same change, which `test_project_map` requires.

8. **Mirror parity** (`tests/test_stream.py`). Extend the existing mirror test, or add one next to it: over a non-symmetric `(H, W, 3)` `uint8` array, the published mirrored image must be `np.array_equal` to `cv2.flip(img, 1)` and C-contiguous. `cv2` is available in the dev env.

9. **README.** In "Installation", change the core line to `# core: numpy only — the stream and pipeline runtime, for a feed of your own` and add `pip install "vision-modules[opencv]"    # + webcams, files, URLs, snapshots`. Rewrite the paragraph below it to match `specs/project.md`: the core needs only numpy; `opencv` adds OpenCV, and any variant works; `hand` adds mediapipe, torch, transformers and pillow. The Quickstart uses `StreamProvider(0)`, so note it needs `[opencv,hand]`.

10. **Statuses.** Once verification passes, mark this plan `Done` (here and in `plans/_index.md`). Flip `specs/project.md`, `stream.md`, `snapshot.md`, `hand.md` and `gesture_classifier.md` from `Updated` back to `Implemented`, both in each file and in `specs/_index.md`.
