# `FrameLike`: type frame consumers against a protocol, not the `Frame` class

**Status:** Done

Implements the settled behavior in `specs/stream.md` ("`FrameLike` — the frame contract consumers type against"), `specs/hand.md` (`HandStage` over `Upstream[FrameLike]`) and `specs/snapshot.md` (`save_frame` / `save_input` over any `FrameLike`), under the rule stated in `specs/pipeline.md` ("a stage names the protocol of what it reads"). Delivers a `@runtime_checkable` `FrameLike` protocol and retypes the three places that named `Frame` nominally, so a host with its own frame class and its own latest-value slot can feed `HandStage` and the snapshot functions with pyright clean and no re-publishing through `StreamProvider`. Nothing changes at runtime for existing callers: `StreamProvider` still publishes `Frame`, and a `Frame` is a `FrameLike`. Deliberately leaves out dtype-precise array typing (`NDArray[np.uint8]`), any per-frame metadata protocol (pose), and making stages generic in their input type.

## Scope

- `src/vision_modules/stream.py` — `FrameLike(HasFrameId, Protocol)` with property members `ts` and `image`, `@runtime_checkable`; `Frame` unchanged.
- `src/vision_modules/hand.py` — `HandStage(Stage[FrameLike, HandResult])`, `provider: Upstream[FrameLike]`, `process(item: FrameLike)`; no more import of `Frame`.
- `src/vision_modules/snapshot.py` — `save_frame(frame: FrameLike | None, …)`; `save_input` dispatches on `isinstance(item, FrameLike)` instead of `isinstance(item, Frame)`.
- `src/vision_modules/__init__.py` — export `FrameLike`.
- `tests/test_hand.py` — a `HandStage` over an upstream whose items are a frame class defined in the test (not `Frame`).
- `tests/test_snapshot.py` — `save_frame` on a foreign frame; `save_input` on a stage whose `last_input` is a foreign frame.
- `README.md` — `FrameLike` in the Stream section and the concepts table; `save_frame` signature.
- `specs/stream.md`, `specs/hand.md`, `specs/snapshot.md`, `specs/_index.md` — flipped `Updated` → `Implemented` when done.
- `plans/_index.md` — this plan's row.

## Steps

1. **Protocol.** In `stream.py`, import `HasFrameId` from `pipeline` (already imports `LatestValue` from there; no cycle) and define `FrameLike` right after `Frame`: `@runtime_checkable class FrameLike(HasFrameId, Protocol)` with `@property def ts(self) -> float` and `@property def image(self) -> np.ndarray`, docstring carrying the BGR / read-only convention.
2. **Hand stage.** Replace `from vision_modules.stream import Frame` with `FrameLike`; retype the class, the constructor parameter and `process`. The body reads only `frame_id`, `ts`, `image` and needs no change.
3. **Snapshot.** Import `FrameLike` instead of `Frame`; retype `save_frame`; change the `save_input` dispatch. Order is irrelevant: `HandResult` has no `image`, so the structural check cannot catch it.
4. **Export.** Add `FrameLike` to `__init__.py` imports and `__all__`.
5. **Hand test.** Define in the test a frozen dataclass `ForeignFrame(frame_id: int, ts: float, image: NDArray[np.uint8])` and a `ForeignFeed` with `latest() -> ForeignFrame | None`; run a `HandStage(feed, detector=ScriptedDetector(...))`; assert the published `HandResult` carries the foreign frame's `frame_id` and `ts`, the crop equals the expected slice of the foreign image, and the detector received the foreign `ts`. The test file is type-checked by pyright, so the assignment `HandStage(feed, …)` is itself the static assertion.
6. **Snapshot tests.** `save_frame(ForeignFrame(...), path)` round-trips the pixels; `save_input(hands, path)` on a `HandStage` fed a foreign frame writes that frame; the existing `TypeError` test still passes for a pixel-less input.
7. **Docs.** README: `FrameLike` next to `Frame` in the Stream API text and concepts table; `save_frame(frame: FrameLike | None, path)`.
8. **Statuses.** The three specs `Updated` → `Implemented` (file and index), this plan → `Done`, in the same change as the verified code.
