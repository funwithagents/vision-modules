# Save a module's input: `Stage.last_input` and `save_input`

**Status:** Done

Implements the settled behavior in `specs/pipeline.md` ("`last_input` is what this stage last looked at") and `specs/snapshot.md` ("Input view", `save_input`). Delivers the exact item a stage last handed to `process()` as a thread-safe, read-only `last_input`, and a `save_input(stage, path)` that writes it by dispatching on its type — so `GestureClassifier`, which publishes no pixels, can still have "its current frame" saved. Deliberately leaves out any change to what stages publish, and the spec's open questions (sidecar metadata, demo button, annotated snapshot).

## Scope

- `src/vision_modules/pipeline.py` — `_input_slot: LatestValue[TIn]`, published in the worker right before `process()`; `last_input` read-only property.
- `src/vision_modules/snapshot.py` — `save_input(stage, path)`: `None` → `ValueError`, `Frame` → `save_frame`, `HandResult` → `save_crops`, else `TypeError`.
- `src/vision_modules/__init__.py` — export `save_input`.
- `tests/test_pipeline.py` — `last_input` is `None` before the first item, is set even when `process()` raises, tracks the stage's own cadence, and survives a restart.
- `tests/test_snapshot.py` — `save_input` on a `HandStage` writes the full frame, on a `GestureClassifier` writes the classified crop, keeps writing that crop after the upstream has moved on, raises before the first `process()`, and raises `TypeError` for an unknown input type.
- `README.md` — `last_input` in the Pipeline API block; `save_input` in the Snapshot section.
- `specs/pipeline.md`, `specs/snapshot.md`, `specs/_index.md` — both flipped `Updated` → `Implemented` when done.
- `plans/_index.md` — this plan's row.

## Steps

1. **Slot.** In `Stage.__init__`, add `self._input_slot: LatestValue[TIn] = LatestValue()` next to `_slot`. It is never reset in `start()`, so it carries across restarts like `latest()`.
2. **Publish before `process()`.** In `_run`, after `_last_id = item.frame_id` and before the `try`, `self._input_slot.publish(item)`. A reference only — no copy.
3. **Property.** `last_input` returns `self._input_slot.get()`, with a docstring stating the "set before `process()`" and "carries over restarts" rules.
4. **`save_input`.** In `snapshot.py`, import `Stage` from `pipeline` (no cycle: `pipeline` imports nothing from `snapshot`) and implement the dispatch chain; error messages name `stage.name`.
5. **Export.** Add `save_input` to `__init__.py` imports and `__all__`.
6. **Pipeline tests.** With the existing `FakeUpstream` / `RecordingStage` / `FlakyStage` doubles: `last_input is None` before start; on `FlakyStage` after item 1 (which raises) `last_input == Item(1)` while `latest()` is still `None`; after the upstream moves to item 2, `last_input == Item(2)` and `latest().frame_id == 2`; in `test_stage_restarts_after_stop_as_a_fresh_run`, assert `last_input` is still item 1 across the stop.
7. **Snapshot tests.** Extend the pipeline-driven test: `save_input(hands, …)` round-trips the full frame. New tests with a `FakeHandStage` + scripted classifier: `save_input(gestures, …)` writes `_0` crop equal to the classified crop; after `gestures.stop()` and replacing the upstream's value, `save_input` still writes the old crop (the stage's own input, not the upstream's newest); `save_input` on an unstarted stage raises `ValueError`; a `Stage` consuming a pixel-less dataclass raises `TypeError`.
8. **Docs.** README Pipeline block gains `.last_input`; Snapshot section gains the `save_input` signature and the `gestures` example.
9. **Statuses.** Both specs `Updated` → `Implemented`, this plan → `Done`, files and indexes, in the same change as the verified code.
