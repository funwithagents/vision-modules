## Steps

1. **Extra.** In `pyproject.toml` add `face-mediapipe = ["mediapipe>=0.10.35,<1.0"]` under `[project.optional-dependencies]` and change `dev`'s entry to `vision-modules[face-mediapipe,hand,opencv]`. `uv sync --dev` so the lockfile follows.

2. **Shared MediaPipe helpers in `hand.py`.** `default_model_path(filename: str = "hand_landmarker.task") -> Path` (same cache dir and `VISION_MODULES_CACHE` rule); `ensure_model` logs `"downloading model to %s"`. Extract `video_ts_ms(ts: float, last_ms: int) -> int` (`int(ts * 1000)`, bumped to `last_ms + 1` when not strictly greater) and use it in `MediaPipeHandDetector.detect`. `test_hand.py` must pass unchanged.

3. **`face.py` — data and seam.**
   - `DetectedFace` as the spec's table: `@dataclass(frozen=True, eq=False)`.
   - `FaceDetector(Protocol)` with `detect` / `close`.
   - Constants: `DEFAULT_MODEL_URL` (the spec's URL), `MODEL_FILENAME = "face_landmarker.task"`, `NOSE_TIP = 1`, `RIGHT_IRIS = 468`, `LEFT_IRIS = 473`, `EXTRA_HINT = 'pip install "vision-modules[face-mediapipe]"'`.
   - Private seam: a `_NativeFace` (frozen dataclass: `landmarks: np.ndarray` `(N, 3)` float32, `matrix: np.ndarray | None` `(4, 4)`) and a `_Landmarker` protocol (`detect(rgb: np.ndarray, ts_ms: int) -> list[_NativeFace]`, `close()`). A module-level `_open_landmarker(model_path, max_faces, det_conf, pres_conf, track_conf) -> _Landmarker` does the `mediapipe` import (re-raising `ImportError` with `EXTRA_HINT` appended), resolves the bundle (`Path(model_path)` if given, else `default_model_path(MODEL_FILENAME)`) and `ensure_model(path, DEFAULT_MODEL_URL)`, builds `FaceLandmarkerOptions` (`RunningMode.VIDEO`, `num_faces=max_faces`, the three confidences, `output_facial_transformation_matrixes=True`, `output_face_blendshapes=False`) and returns a small adapter class. The adapter wraps `rgb` in `mp.Image(SRGB)`, calls `detect_for_video`, and turns `face_landmarks[i]` into a float32 `(N, 3)` array and `facial_transformation_matrixes[i]` into a `(4, 4)` array. Tests monkeypatch `face._open_landmarker`.

4. **`face.py` — orientation.** `orientation_from_matrix(m: np.ndarray) -> tuple[float, float, float]` (public within the module for testing; not re-exported). Take `R = m[:3, :3]` and normalise its columns (drop any scale). Decompose as `R = Rz(a) · Ry(b) · Rx(c)`: `b = asin(clip(-R[2, 0], -1, 1))`, `c = atan2(R[2, 1], R[2, 2])`, `a = atan2(R[1, 0], R[0, 0])`. Starting mapping, assuming MediaPipe's camera frame is OpenGL-like (x right, y up, z toward the viewer): `roll = -a` (counter-clockwise about +z, as seen by the camera, is counter-clockwise in the image), `pitch = c` (+x rotation brings the top of the head toward the camera: chin down), `yaw = b` (+y rotation turns the face's forward axis toward +x: image right). **This mapping is a hypothesis until step 8's live tests confirm each sign.** If one disagrees, fix the mapping here and update step 5's synthetic expectations with it. The spec's convention is what's fixed; this formula isn't.

5. **`face.py` — `MediaPipeFaceDetector`.**
   - `__init__`: validate `max_faces >= 1` (`ValueError`) first, then `self._lm = _open_landmarker(...)`, `self._last_ts_ms = -1`, `self._closed = False`.
   - `detect`: `RuntimeError` if closed; `rgb = np.ascontiguousarray(image_bgr[..., ::-1])`; `ts_ms = video_ts_ms(ts, self._last_ts_ms)`; map each `_NativeFace`: box = clamped min/max of `landmarks[:, 0]` / `[:, 1]`; `nose = landmarks[NOSE_TIP, :2]`; `eyes = (landmarks[RIGHT_IRIS, :2], landmarks[LEFT_IRIS, :2])` (index-guarded: `None` if the mesh is shorter than 474 points); `orientation = orientation_from_matrix(matrix)` or `None`; `landmarks` as float32; `score=None`. Plain Python floats in every tuple.
   - `close`: idempotent; closes the landmarker once.

6. **Exports and map.** Re-export `DetectedFace`, `FaceDetector`, `MediaPipeFaceDetector` from `vision_modules/__init__.py` (and `__all__`). Add the `face.py` row to AGENTS.md's project map (role: "`FaceDetector` seam, `DetectedFace`, `MediaPipeFaceDetector` — faces with box, nose, eyes, orientation and landmarks", spec `specs/face.md`).

7. **Fast tests.**
   - `tests/test_face.py`, with a fake landmarker via `monkeypatch.setattr(face, "_open_landmarker", ...)`. The fake records `(rgb, ts_ms)` per call and returns scripted `_NativeFace`s. Build a synthetic 478-point mesh with known extremes (some points outside `[0, 1]` to exercise clamping) and distinct values at 1 / 468 / 473. Cover every assertion listed in face.md "Tests": box, nose, eyes order, landmarks shape/dtype, `score is None`, `max_faces=0` raising `ValueError` (with a fake that fails if called, to prove validation happens first), timestamps for equal/decreasing `ts`, RGB/contiguous/untouched caller array, `detect` after `close` raising `RuntimeError`, double `close` closing the fake once.
   - Orientation via `orientation_from_matrix`: identity gives `(0, 0, 0)`; for `θ = ±15°`, matrices built from independent `Rx`/`Ry`/`Rz` helpers in the test, with signs per step 4's mapping (roll `+θ` ⇐ `Rz(−θ)`, pitch `+θ` ⇐ `Rx(θ)`, yaw `+θ` ⇐ `Ry(θ)`), give that angle alone within 1e-6. Also check that a uniformly scaled matrix decomposes the same.
   - `tests/test_core_imports.py`: in the blocked subprocess, `from vision_modules.face import MediaPipeFaceDetector` succeeds and `MediaPipeFaceDetector()` raises `ImportError` containing `vision-modules[face-mediapipe]`.

8. **Fixtures and live tests.**
   - Source three **public-domain or CC0** photos (Wikimedia Commons "Public domain"/CC0 categories, or US-government works), one clearly visible adult face each: `face_frontal.jpg` (upright, looking at the camera, a neutral background preferred), `face_yaw_right.jpg` (head turned ≈ 20–40° toward the image's right), `face_pitch_down.jpg` (facing the camera, head clearly tilted down). Downscale to ≤ 640 px on the long side, re-encode as JPEG. In `tests-e2e/fixtures/README.md`, add a "Face fixtures" section: per file, the pose it shows and what uses it, the source page URL, the author and the licence. Update the README's closing licence paragraph so it no longer claims every fixture is an original photo.
   - `tests-e2e/support.py`: `face_image_path(name: str) -> Path` skipping with a message naming the file when absent.
   - `tests-e2e/test_face_live.py`, one fresh `MediaPipeFaceDetector` per independent image, closed in `finally`. Cover every assertion in face.md "Tests". Rotate clockwise by `θ` with `cv2.warpAffine(img, cv2.getRotationMatrix2D(center, -θ_deg, 1.0), (w, h))` (OpenCV's positive angle is counter-clockwise). Side by side with `np.hstack([img, img])`, then check the two boxes don't overlap. For the threading check, run ten calls, each in a new `threading.Thread` joined before the next starts, so the calls are guaranteed to come from ten distinct threads and never overlap. (A `ThreadPoolExecutor` fed one call at a time reuses its idle worker, so it wouldn't test this.)
   - Run `uv run pytest tests-e2e/test_face_live.py`. If a yaw/pitch/roll sign fails, fix step 4's mapping and step 7's expectations, not the tests' thresholds.

9. **README.** Add `pip install "vision-modules[face-mediapipe]"` to the install block and describe the extra where the "future feature family (faces, poses)" sentence is. Add a short "Face detector" section: construct, `detect(image_bgr, ts)`, the normalised fields, the orientation convention in one line, the threading rule, `close()`, pointing to specs/face.md. Add `face_landmarker.task` to the downloaded-models table (same cache as the hand bundle).
